# Support

Use the [GitHub Issues](https://github.com/jjunho/count-words/issues) page to report bugs, ask questions, or suggest improvements. Search existing issues before opening a new one.

## Reporting a bug

Include enough detail for someone else to reproduce the problem:

- Steps to reproduce, including the file type and whether you selected text.
- Expected result and actual result.
- VS Code version from **Help → About**.
- Extension version from the Extensions view.
- Operating system and version.
- A small example document or selection that does not contain private content.

Remove passwords, access tokens, private documents, and other personal data before attaching examples or logs.

## Reproduction checklist

1. Reproduce the issue in a new VS Code window when possible.
2. Confirm whether it affects the whole document, a selection, or both.
3. Note whether the issue persists after reopening the document.
4. Attach screenshots or logs only after removing sensitive information.

For feature requests, describe the problem you want to solve and the expected result. Please do not include credentials or other secrets in an issue.
